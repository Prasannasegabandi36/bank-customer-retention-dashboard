## 🚀 Project Summary

This project is a professional **Bank Customer Retention Intelligence Dashboard** designed to help banks understand customer churn behavior, identify high-risk customers, and create data-driven retention strategies.

Instead of analyzing churn only through basic customer demographics, this project focuses on:

- Customer behavior
- Product utilization
- Active membership
- Relationship strength
- Churn risk intelligence
- Machine learning-based prediction

The final output is an interactive **Streamlit dashboard** that converts raw banking customer data into clear business insights.

---

## 🎯 Business Problem

Customer churn is a major challenge in the banking industry. Losing customers affects revenue, relationship value, and long-term business growth.

Banks need to know:

- Why are customers leaving?
- Which customers are likely to churn?
- Which customer segments need attention?
- How does product usage impact retention?
- What actions can reduce churn?

This project solves that problem using analytics and machine learning.
